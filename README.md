# Ecommerce_sql_business_analysis

## Project Overview

This project analyzes an e-commerce dataset using SQL to uncover
business insights related to customers, sales, products, profitability,
payments, and returns.

The analysis uses SQL techniques to answer real-world business questions
and identify patterns that can support better business decisions.

## Business Questions

This project answers key business questions across customers, sales,
products, payments, and returns:

- Which customers generate the highest revenue?
- Which products generate the highest sales and profit?
- Which categories perform best based on sales and profit?
- Which regions contribute the most revenue?
- Which payment methods are most successful?
- Which products have the highest return impact?
- How do customers behave across acquisition cohorts?
- Which products have high sales but low profit margins?
- Which products lose the most potential profit because of returns?
- Which products fall into different sales and profit performance groups?
